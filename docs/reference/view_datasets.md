# List of Datasets in the ColombiAPI Package

This function lists all the datasets available in the ColombiAPI
package. It returns a character vector with the names of the datasets
included in the package.

## Usage

``` r
view_datasets()
```

## Value

A character vector containing the names of the datasets available in the
ColombiAPI package.

## Examples

``` r
# List the datasets available in the ColombiAPI package
view_datasets()
#> Datasets available in the ColombiAPI package:
#> [1] "Bogota_airstations_df"       "Bogota_business_Date"       
#> [3] "Bogota_holidays_Date"        "Bogota_malls_tbl_df"        
#> [5] "Cannabis_Licenses_tbl_df"    "Colombia_coffee_tbl_df"     
#> [7] "Medellin_rain_tbl_df"        "Tulua_Public_Schools_tbl_df"
```
